A clean extension implementation first needs a small core completion-provider API; prototype monkey-patching from a plugin is technically possible but unsupported and brittle.

The bundled `file-mentions` plugin owns `@` file/folder discovery; the fullscreen TUI owns picker rendering and keyboard behavior. Quoted references support paths containing spaces.
